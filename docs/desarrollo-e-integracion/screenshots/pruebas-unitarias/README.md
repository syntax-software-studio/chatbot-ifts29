# Screenshots - Pruebas Unitarias

En esta carpeta se guardan las capturas de pantalla de la ejecución de pruebas unitarias.

## Archivos esperados:

- `01-ejecucion-ide.png` - Ejecución de pruebas desde el IDE (IntelliJ, Eclipse, VS Code, etc.)
- `02-cobertura.png` - Reporte de cobertura de código
- `03-resultado-consola.png` - Salida por consola de la ejecución
- `04-detalles-pruebas.png` - Detalles de cada prueba ejecutada

## Nombrado sugerido:

```
01-ejecucion-ide.png          (resultado de ejecutar pruebas)
02-cobertura-codigo.png        (reporte de cobertura JaCoCo/similar)
03-consola-ejecucion.png       (output en consola)
04-prueba-exitosa.png          (detalle de prueba pasada)
05-prueba-fallida.png          (si existe alguna)
06-reporte-maven.png           (si usa Maven)
07-estadisticas.png            (resumen de resultados)
```

> **Nota:** Las capturas deben mostrar claramente el éxito de las pruebas y la cobertura de código alcanzada.
