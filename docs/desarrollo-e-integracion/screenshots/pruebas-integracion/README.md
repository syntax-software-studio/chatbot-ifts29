# Screenshots - Pruebas de Integración

En esta carpeta se guardan las capturas de pantalla de la ejecución de pruebas de integración.

## Archivos esperados:

- `01-ejecucion.png` - Ejecución de suite de pruebas de integración
- `02-resultado-final.png` - Resultado final exitoso de las pruebas
- `03-flujo-[funcionalidad].png` - Flujos de usuario durante las pruebas
- `04-base-datos-resultado.png` - Verificación de datos en BD
- `05-consola-integracion.png` - Output por consola

## Nombrado sugerido:

```
01-ejecucion-suite.png         (inicio/ejecución de pruebas)
02-resultado-exitoso.png       (resultado final 100% exitoso)
03-flujo-registro.png          (flujo de registro en interfaz)
04-flujo-crud-crear.png        (operación CREATE)
05-flujo-crud-leer.png         (operación READ)
06-flujo-crud-actualizar.png   (operación UPDATE)
07-flujo-crud-eliminar.png     (operación DELETE)
08-validacion-error.png        (manejo de errores)
09-base-datos-verificacion.png (verificación en BD)
10-estadisticas-integracion.png (resumen de resultados)
```

## Tipos de Pruebas a Documentar:

1. **Flujo de Registro** - Del registro al login exitoso
2. **Operaciones CRUD** - Crear, Leer, Actualizar, Eliminar registros
3. **Validaciones** - Manejo de errores y validaciones
4. **Integración BD** - Persistencia de datos

> **Nota:** Las capturas deben mostrar claramente que todos los módulos trabajan conjuntamente sin errores.
