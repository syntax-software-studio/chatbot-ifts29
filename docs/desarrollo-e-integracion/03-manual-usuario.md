## 3. Instalación y Puesta en Marcha

### 3.1 Descargar la Aplicación

1. Visita [enlace de descarga o repositorio]
2. Descarga el archivo: `PP4-Bot-IFTS29-v1.0.[exe/apk/jar]`
3. Guarda el archivo en una carpeta conocida

### 3.2 Instalar la Aplicación

**En Windows:**
1. Haz doble clic en el instalador
2. Sigue los pasos del asistente de instalación
3. Selecciona la carpeta de destino
4. Haz clic en "Instalar"

**En macOS:**
1. Abre el archivo `.dmg`
2. Arrastra la aplicación a la carpeta "Aplicaciones"
3. Abre Aplicaciones y haz clic en PP4 Bot IFTS29

**En Linux:**
```bash
tar -xzf pp4-bot-ifts29.tar.gz
cd pp4-bot-ifts29
./install.sh
```

### 3.3 Primera Ejecución

1. Busca el ícono de PP4 Bot IFTS29 en tu escritorio o menú de inicio
2. Haz doble clic para abrir la aplicación
3. Espera a que cargue completamente (puede tomar 5-10 segundos)

### 7.2 Mensajes de Error

| Mensaje | Significado | Solución |
|---------|------------|----------|
| "Campo obligatorio vacío" | Falta completar un campo requerido | Completa todos los campos marcados con * |
